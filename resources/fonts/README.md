# Font KTM

Dipakai GD saat menggambar KTM digital (JPG), karena GD hanya membaca berkas TTF lokal.

- DM Sans (Regular, Bold): font utama. Sumber: Google Fonts, lisensi SIL Open Font License 1.1.
- DejaVu Sans (Regular, Bold): cadangan untuk teks berhuruf di luar cakupan DM Sans, misalnya nama
  Vietnam. Lisensi: lihat https://dejavu-fonts.github.io/License.html
